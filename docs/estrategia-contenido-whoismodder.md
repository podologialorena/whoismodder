# Estrategia de contenido whoismodder

## Objetivo

Usar `@whoismodder` en X, Instagram y TikTok para construir deseo, autoridad y contexto antes de mandar gente a comprar.

La idea central que tiene que repetirse:

```text
El algoritmo opera. Tus cuentas copian.
```

La explicacion corta:

```text
El algoritmo da la orden. Mod Menu MNQ copia esa orden hacia grupos de cuentas, respetando cuentas activas, cuentas pausadas y riesgo por cuenta.
```

## Perfil

Bio sugerida:

```text
El algoritmo opera. Tus cuentas copian.
Mod Menu MNQ v1
Acceso limitado
```

Link principal:

```text
https://whoismodder.com.ar
```

No usar Linktree como link principal. La landing propia muestra directamente el SaaS y separa la intencion antes de mandar a Whop.

## Funnel

```text
Redes sociales
  -> whoismodder.com.ar
    -> Que es Mod Menu MNQ en 10 segundos
    -> El problema: muchas cuentas sin estructura copian todo igual
    -> El mecanismo: orden / filtro / copia / control
    -> Conectar mis cuentas
      -> whoismodder.com.ar / acceso limitado
    -> Construir mi sistema
      -> Mod Menu MNQ Builder en Whop
    -> Entender primero
      -> Blueprint en Whop
```

## Primeras 9 piezas del perfil

1. El algoritmo opera. Tus cuentas copian.
2. Que es Mod Menu MNQ: la capa entre el algoritmo y tus cuentas.
3. Una orden no tiene que ir a todas las cuentas.
4. Un grupo puede tener cuentas activas y pausadas.
5. Cada cuenta puede tener su propio riesgo.
6. Apex 20 cuentas / Lucid 5 cuentas / CFD proximamente.
7. Que NO es: no ordenes vendidas, no promesas, no ganancias garantizadas.
8. Builder: arma tu estructura.
9. Acceso limitado.

## Pilares de contenido

### Sistema

Mostrar pantallas, diagramas, cambios de la landing, flujo de orden, copia por grupo, riesgo por cuenta y logs.

Ejemplos:

```text
No estoy armando una comunidad de ordenes.
Estoy armando una capa para copiar ordenes a grupos de cuentas.
```

```text
La orden entra una vez.
Despues cada grupo decide que cuentas participan.
```

### Dolor

Mostrar el problema de operar o copiar cuentas sin estructura.

Ejemplos:

```text
El problema no es tener 20 cuentas.
El problema es tratarlas como si fueran una sola.
```

```text
Copiar todo igual es simple.
Controlar que copia cada cuenta es otra cosa.
```

### Control

Mostrar estado activo/pausado, riesgo por cuenta, grupos por prop firm y logs.

Ejemplos:

```text
Apex puede copiar.
Lucid puede copiar.
FTMO puede quedar fuera.

La orden es una.
La ejecucion no tiene que ser igual para todos.
```

```text
Una cuenta pausada no deberia frenar todo el grupo.
Y una cuenta activa no tiene por que usar el mismo riesgo que otra.
```

### Construccion publica

Mostrar avances sin depender de mostrar la cara.

Ejemplos:

```text
Hoy cambie el enrutador.
Antes parecia que todo se copiaba igual.
Ahora separa estado y riesgo por cuenta.
```

```text
La landing no tiene que explicar de mas.
Tiene que hacer sentir estructura.
```

### Oferta

Vender poco y claro.

Ejemplos:

```text
Mod Menu MNQ v1 esta en acceso limitado.
Primero grupos chicos.
Despues escala.
```

```text
Builder es para quien quiere entender y montar su propia estructura.
No para quien busca promesas rapidas.
```

## Cadencia inicial

Durante 14 dias:

- X: 2 posts por dia.
- Instagram: 1 reel o carrusel por dia.
- TikTok: 1 video corto por dia.

Reutilizar la misma idea en distintos formatos:

- X: texto directo + captura.
- Instagram: carrusel visual.
- TikTok: pantalla grabada + texto encima.

## Reglas de comunicacion

Evitar:

- Ganancias prometidas.
- "Sin riesgo".
- "Pasar fondeos garantizado".
- "Hacer X dolares".
- Rentabilidad futura.
- Antes/despues de plata.
- Lenguaje de inversion asesorada.

Usar:

- Infraestructura.
- Cuentas conectadas.
- Orden.
- Copia por grupo.
- Riesgo por cuenta.
- Acceso limitado.
- Construccion publica.
